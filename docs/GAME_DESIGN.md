# 游戏设计基线（挂机 / 群友题材）

本文件只记录**已接受的决策**。未决策项列在第 4 节，任务遇到它们时保持 BLOCKED，不要在实现中偷偷决定。

## 1. 一句话定位

把「我加的各大聊天群和群友」变成卡池的本地单机挂机游戏：挂机产出 → 抽群友卡 → 群友自动产出 → 合成与转生。

设计目标不是复刻真实群聊，而是**让加一个群等于加一份数据包，零改代码**。

## 2. 已决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 群友信息**全部化名 + 程序生成头像** | 真实昵称/言论会让群友看到自己被评成「稀有度 N」，且事后改数据模型成本极高。 |
| D2 | 平台：**网页，浏览器本地存档** | 最快出可玩版本；改一行刷新即可验证；可直接给群友发链接试玩。 |
| D3 | **不接 QQ/微信等聊天 API，不抓取聊天记录** | 封号风险、账号风险、复杂度爆炸。数据由用户手动填写或导出的 JSON 提供。 |
| D4 | 第一版**只有一条产出轴**：群活跃度 | 多资源会让数值立刻失控。其余货币一律是它的换算。 |
| D5 | 稀有度按**可观测行为**判定（发言频率、深夜在线、斗图、潜水），不按个人喜好 | 化名之后依然传神，且可自动从统计信息推导。 |
| D6 | 转生机制用**「退群 / 群解散」**包装 | prestige 与题材天然同构，是本题材最值钱的一点。 |
| D7 | 内容必须**可加包**，梗不得硬编码进逻辑 | 梗有半衰期，内容会腐化。 |
| D8 | 分层：数据（JSON）/ 模拟（纯函数、确定性）/ 渲染 | 离线收益、合成、转生都要能跑确定性测试（对齐 AGENTS.md 第 3 节）。 |

## 3. 核心循环

```text
挂机时间
  -> 群活跃度（唯一产出轴）
  -> 抽群友卡（群 = 卡池兼地图）
  -> 群友 = 自动产率
  -> 合成：两个群友 -> CP 卡（传播点）
  -> 退群 / 群解散 = 转生重置 -> 永久倍率提升
  -> 回到群活跃度
```

长线来自**解锁新群**（不同群的产率与稀有度分布不同），不是来自堆数值上限。

## 4. 未决策（遇到请标记 BLOCKED）

- 群活跃度的具体公式与离线收益上限算法。
- 抽卡消耗与稀有度概率表。
- CP 卡合成的匹配规则（标签交集？固定配方表？）。
- 转生永久倍率的曲线。
- 存档格式与版本字段。
- 美术风格与头像生成算法（当前只冻结「程序生成」这一点）。
